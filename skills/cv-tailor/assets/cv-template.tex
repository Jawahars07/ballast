% One-page ATS-safe CV template
%
% Compile with:  tectonic cv-template.tex
% NOT pdflatex. Tectonic runs shell-escape disabled and needs no TeX Live.
%
% Design rules — do not drift from these without a reason you can state:
%   * single column, no tables in the body, no text boxes, no header/footer
%   * standard section names only (Education / Experience / Projects / Skills)
%   * greys only, so it survives a black-and-white print
%   * hyperlinked contact row, never a bare URL as visible text
%   * NEVER \uppercase inside titlesec — it breaks under tectonic. Use \scshape.
%   * NEVER hidden, white, or zero-opacity text. ATS platforms flag it as fraud.
%==============================================================================
