# examples

Starting points. Copy them into your own working directory and replace the contents.

| File | What it is |
|---|---|
| `facts.md` | **The only source of claimable facts.** Nothing reaches a document unless it is here |
| `profile.yml` | Constraints, exclusions, hard gates, granted exceptions |
| `applications.tsv` | The tracker. Tab-separated. `num` is max(num) + 1, never a report number |

None of these leave your machine. No skill in this repository uploads, transmits, or phones home
with anything in them.
